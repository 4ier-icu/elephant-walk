### 大象漫步支持哪些操作系统和桌面环境？

支持四个平台：
- **macOS**：Apple 芯片（M1 及以上），macOS 13 或更新版本。
- **Windows**：Windows 10 与 Windows 11（提供 x64 便携 `.exe` 与 ARM64 `.zip` 包）。
- **Linux**：64 位 x86_64 系统，支持 **GNOME、KDE、X11 和 niri**（同时覆盖 Wayland 与 X11；暂不支持 Linux ARM64）。
- **Android**：Android 11 或更新版本的手机与平板。

目前**不支持** iPhone 和 iPad（iOS / iPadOS）、Intel 芯片的旧款 Mac 以及 ARM64 架构 Linux。

### 局域网里的键盘输入和剪贴板是加密传输的吗？

是的。所有键盘输入、鼠标移动、手势和剪贴板内容全部在你的局域网内点对点直连，不经过任何云端服务器：
- 控制和剪贴板通道强制使用 **TLS 1.3 双向证书认证（mTLS）**，并校验每台设备的 **Ed25519 公钥 SHA-256 指纹**；
- 高频指针 UDP 数据报使用由 TLS 会话导出的双向独立密钥，采用 **AES-256-GCM** 加密与单调递增防重放序号。

完整技术细节和自己抓包验证的方法，请查看[安全与加密](../security/)。

### Android 设备需要 Root 或 Shizuku 吗？

都不需要。大象漫步在 Android 11 及以上版本中，只需首次打开时按屏幕引导开启“开发者选项”和“无线调试”完成一次本机授权，即可获得完整的跨应用鼠标、实体键盘、多指手势与后台双向文字/图片剪贴板能力。不依赖 Shizuku，不申请无障碍服务，也不申请通知权限。

### Linux Wayland 下好用吗？需要手动填 IP 吗？

大象漫步原生支持 Linux Wayland（GNOME、KDE、niri）与 X11，并且采用局域网自动发现，不需要手动填写 IP 地址或端口；换 Wi-Fi 后重新连入同网设备会自动重连并恢复原有屏幕排列。

### 没网的时候（纯局域网）能用吗？

可以。完成初始激活后，日常跨设备键鼠与剪贴板完全在本地局域网直连运行，不依赖互联网；仅在设备联网时定期检查许可状态与版本更新。
