# 安全与加密

大象漫步（Elephant Walk）是一款纯局域网运行的跨屏键鼠共享软件。跨屏键鼠应用拥有系统级输入与剪贴板权限，因此这里把实际生效的加密协议、权限边界、网络访问范围以及独立核验方法全部公开。

## 1. 局域网传输加密（端到端直连，不经云端）

你的键盘输入、鼠标移动、触控板手势、剪贴板文字和图片、屏幕排列，**全部只在你自己的局域网内，在受信任的设备之间点对点加密传输**，绝不经过或上传至任何中继服务器。

| 通信通道 | 实际加密与认证机制 |
| --- | --- |
| **控制与剪贴板通道（TCP）** | 强制 **TLS 1.3** 双向证书认证（mTLS）。每台设备在本地生成独立的 **Ed25519** 密钥对与自签名 X.509 证书，每次握手均校验对端证书的 **SHA-256 公钥指纹**（公钥固定），并通过 ALPN 绑定协议版本、通道类型与设备组标识。 |
| **高频指针位置通道（UDP）** | 不使用明文，也不复用静态密钥。每次已认证的 TLS 1.3 连接建立后，通过标准 TLS 密钥导出（`ExportKeyingMaterial`）为发送与接收两个方向分别派生独立的 256 位密钥，使用 **AES-256-GCM** 认证加密，并配合严格单调递增的 64 位防重放序号；连接关闭后立即作废。 |
| **多账户网络隔离** | 登录账户后，设备间连接会校验账户证书。即使在同一局域网（例如办公室或合租 Wi-Fi）存在其他人的设备，携带不同账户证书的设备也会在握手阶段被拒绝。 |

## 2. 哪些数据会访问互联网？

大象漫步应用本体**没有任何行为统计、埋点或遥测**。仅在以下明确场景下访问公网 HTTPS 接口：

- **登录、试用与许可核验（`license.4ier.icu`，托管于 Cloudflare）**：用于邮箱验证码登录、防普通卸载重装重复试用的单向设备摘要核验、许可激活与每 30 天一次的退款/撤销状态同步。原始硬件标识、设备名称、屏幕排列、按键和剪贴板内容**绝不上传**。详情见[隐私政策](https://ew.4ier.icu/zh/privacy/)。
- **软件下载与自动更新（`download.4ier.icu`）**：拉取当前平台的更新清单与安装包。
- **购买与收据邮件**：付款由名义销售商 **Paddle.com** 处理；登录验证码与许可码邮件由 **Resend** 发送。

**离线可用**：完成登录和许可激活后，日常断网或纯内网环境下仍可正常跨设备共享键鼠与剪贴板；联网时仅定期同步许可状态。

## 3. 各平台权限为什么需要？

大象漫步坚持各平台最小必要权限原则：

- **macOS（Apple 芯片，macOS 13 及以上）**：需要“本地网络”（发现同网设备）、“辅助功能”与“输入监控”（跨屏时捕获与注入系统级键鼠事件）。
- **Windows（Windows 10 / 11）**：绿色便携版 `ElephantWalk.exe`，日常运行无需安装器或管理员权限；仅需允许局域网专用网络防火墙通行。因目前尚未购买微软商业代码签名证书，首次运行可能出现 SmartScreen 蓝屏提示，可在核验下载来源后选择“仍要运行”。
- **Linux（64 位，GNOME / KDE / X11 / niri）**：默认安装在当前用户目录（`~/.local/share/elephant-walk`）。安装脚本仅在你需要“锁屏界面也能输入”时请求一次本地密码配置 `uinput` 虚拟输入设备，**绝不会**把用户加入可读取实体键盘的 `input` 组；拒绝该授权后，解锁桌面后的跨屏共享仍可正常使用。
- **Android（Android 11 及以上）**：首次配置按引导开启“开发者选项”和“无线调试”完成一次本机输入授权。**不需要 Root、不需要 Shizuku、不申请无障碍服务、不申请通知权限**。

## 4. 如何自己独立验证网络行为？

虽然大象漫步目前是闭源商业软件，但你可以用常见抓包和防火墙工具亲自验证：

1. **查看外连目标**：在 macOS 使用 Little Snitch / LuLu，或在 Linux / Windows 使用防火墙或 `netstat` / `ss`，观察正常打字、移动鼠标、复制文字和图片期间，进程是否向公网 IP 发送任何数据包（正常跨屏操作只会与同局域网内设备通信）。
2. **抓包确认加密载荷**：使用 Wireshark 或 `tcpdump` 抓捕两台同网设备之间的流量，可以看到 TCP 握手为 TLS 1.3 加密流量，UDP 指针包（包头标识 `EWM1`）载荷为不可读的 AES-256-GCM 密文，不存在明文键码或剪贴板正文。
